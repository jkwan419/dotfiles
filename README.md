# My Dotfiles

Personal configuration files for macOS. One command to set up a new machine the way I like it.

---

## What's Included

- **Shell** — Zsh configuration, aliases, functions, and environment variables
- **Neovim** — Editor config, plugins, and keybindings
- **Tmux** — Session management, keybindings, and status bar
- **Ghostty** — Terminal behavior, color theme, font, and keybindings
